# 密码语义（三条）

1. **全新安装**：初始密码 = 安装向导里填的那个；向导留空则用包内默认口令。**首次登录会强制改密一次**（上游对初始密码的保护，正常）。
2. **保留数据重装**：向导里的密码**不生效**，必须用**原来的密码**（安装日志会明确写出）。
3. **密码只存哈希，无法查看，只能重置**。`@appconf/mail-archiver-fnos/admin_password`（600）是上次写入的明文副本，**仅作线索，可能已过期**。

## 忘记密码

首选：**应用中心 → 邮件归档 → 应用设置 → 运行设置 → 管理员登录密码**（填入新密码保存，**立即生效**，无需重启）。

CLI 兜底与网关异常的处理、以及「管理员登录密码 ≠ 数据库口令」的区分，见 **[`FORGOT-PASSWORD.md`](FORGOT-PASSWORD.md)**。

## 安全提醒

- 安装日志中的口令为**掩码**（如 `Ma****6!`）；完整明文只在 `@appconf/.../admin_password`（600）
- **勿截图或外传安装日志**；求助排障前先确认截图不含账号、口令、邮箱地址
- 忘记密码**不会导致数据丢失**——库里是账号与邮件，重置只换登录凭据
