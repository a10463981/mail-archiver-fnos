# 密码语义（三条）与忘记密码的自救路径

## 三条语义

1. **全新安装**：初始密码 = 安装向导里填的那个；向导留空则用包内默认口令。**首次登录会强制改密一次**，属上游对初始密码的保护，正常现象。
2. **保留数据重装**：向导里的密码**不生效**，必须用**原来的密码**（安装日志会明确写出这一点）。
3. **密码只存哈希，无法查看，只能重置**。`@appconf/mail-archiver-fnos/admin_password`（权限 600）保留的是上次设置/安装时写入的明文副本，**仅作线索，可能已过期**。

## 忘记密码怎么办

| 顺序 | 做法 | 位置 / 命令 |
|---|---|---|
| 1（首选） | **应用设置 → 运行设置 → 管理员登录密码**，填入新密码保存 | 立即生效，无需重启 |
| 2 | 命令行重置（CLI 兜底） | `docker exec -e MFA_RESET_PASSWORD='新密码' mail-archiver-fnos dotnet MailArchiver.dll --reset-password admin` |
| 3 | 网关身份异常、进不去时先解绑 | `docker exec mail-archiver-fnos dotnet MailArchiver.dll --unbind admin` |

补充：

- 设置页重置若提示「应用未运行」，请先到应用中心启动应用（不会静默失败）。
- 账号被锁定/限流时，等待限流窗口结束或重启容器清零计数。
- 不要尝试「查看密码」——库里只有哈希。

## 安全提醒

- 安装日志里的口令是**掩码**（如 `Ma****6!`）；**完整明文只在 `@appconf/.../admin_password`（600）**。
- **勿截图或外传安装日志**；求助排障前先确认截图不含账号、口令、邮箱地址。
