# 密码语义（三条）

1. **全新安装**：初始密码 = 安装向导里填的那个；向导留空则用包内默认口令。**首次登录会强制改密一次**（上游对初始密码的保护，正常）。
2. **保留数据重装**：向导里的密码**不生效**，必须用**原来的密码**（安装日志会明确写出）。注意：「保留数据」只说明应用脚本保留了 `@appdata`，**不要当备份用**；普通卸载不动 `@appshare`，但「清理残留」或手动删会丢数据——重要数据先 `pg_dump`，见 [`DATA-DIRECTION.md`](DATA-DIRECTION.md)。
3. **密码只存哈希，无法查看，只能重置**——重置入口见下，不要去找什么"明文副本"。

## 忘记密码

首选：**应用中心 → 邮件归档 → 应用设置 → 运行设置 → 管理员登录密码**（填入新密码保存，**立即生效**，无需重启）。

CLI 兜底与网关异常的处理、以及「管理员登录密码 ≠ 数据库口令」的区分，见 **[`FORGOT-PASSWORD.md`](FORGOT-PASSWORD.md)**。

## 安全提醒

- 安装日志里的口令是**掩码**，不含明文；**勿截图或外传安装日志**，求助排障前先确认截图不含账号、口令、邮箱地址
- 忘记密码**不会导致数据丢失**——库里是账号与邮件，重置只换登录凭据
