# 数据目录：为什么必须走"卸载(保留数据)→重装"

0.1.22 起运行期不支持切换数据目录（设置页只读）。

## 鸡生蛋问题
fnOS 的「访问权限授权」是**针对已安装应用**的，应用没装就没有它、也无从授权。因此"安装时指定目录"成立的前提是：
**该目录已对本应用可写**（属主 987:982 或授权且 ACL 真的生效）。

## 唯一 SOP
1. 用**默认目录**安装一次
2. 应用设置 → 访问权限 → 授权目标目录
3. 卸载（**保留数据**）→ 重装时在向导里指定该目录

## socket 落点（0.1.23 起固定）
应用只监听 **`/vol1/@appcenter/<app>/app.sock`**（网关按此注册）。旧版曾把载荷写成 `/var/apps/<app>/app.sock`，导致 Kestrel 绑定失败/网关 502。**不要改回 APPDEST 路径。**
