# 数据目录与卸载语义（重要）

应用只管理自己的**标准数据目录**：`/vol1/@appdata/mail-archiver-fnos/data`。
如果你把数据改到别处（例如 `/vol1/1000/MailArchive`），那条路径只是一个**符号链接**，**目标目录由你管理，应用不会删除它**。

| 标准数据根形态 | 卸载选「保留数据」 | 卸载选「删除数据」 |
|---|---|---|
| **真实目录**（`@appdata/.../data`） | 保留整目录，重装沿用旧账号 | 删除应用自有目录；重装得到全新空库 |
| **符号链接**（指向你的存储空间目录） | 保留链接与目标，重装沿用旧账号 | **只删符号链接本身**；你目录里的数据**一个字节都不会动**（日志会打印"保持不动"+绝对路径） |

## 切换数据目录会发生什么（0.1.16 起）

1. 应用会被停止 → **迁移成功后自动重新启动**
2. **新目录是空库**（0 账号、0 邮件）——应用只会使用新目录里的数据
3. 原数据**完整保留**在 `@appdata/mail-archiver-fnos/data.bak-<时间戳>`，**没有被删除**
4. 如需沿用旧数据：先把该 `.bak` 目录内容迁到新目录，再重启应用

> 一句话：**"删除数据"删的永远是应用自己的东西；你的存储空间目录只能你自己删。**
