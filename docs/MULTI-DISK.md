# 多磁盘怎么放（SSD 系统盘 + HDD 数据盘）

默认情况下，数据放在**系统分配的共享目录**（`data-share`，通常在 `/vol1/@appshare/mail-archiver-fnos/data`），安装时由 fnOS 自动创建并授权，**不需要**手工 `chown` 或授权。

如果你有独立 HDD 数据卷（如 vol2），希望归档数据放在数据盘上：

1. **先 `pg_dump` 导出**，再**卸载** —— 换位置必须在安装期决定，且卸载时平台会删 `@appshare`，不先备份就会丢数据
2. 重装时在向导的「数据目录」里填 `/vol2/1000/<你的目录>`
3. 该目录需要应用运行用户可写：优先用平台「访问权限」授权应用；若该卷 ACL 不生效，再退回到 `chown -R 987:982 <目录>`
4. 装完启动，确认首页可打开、数据目录指向正确

**为什么不能热切换**：Docker 需要在容器启动时就 bind 挂载该目录，运行中无法热增挂载；强行切换意味着服务中断和数据搬一半的风险。

⚠ 三条硬事实：

- 数据在**默认共享目录**（`@appshare`）时，卸载（**任何选项**）都会被平台删掉 → 想长期保住，装机时就指到 `/vol2/1000/...` 这类个人目录；
- 在**个人目录**（`/vol1/1000/...`、`/vol2/1000/...`）里的数据，平台卸载**不会删**；
- 无论放哪里，**卸载/升级前都先 `pg_dump`**（命令见 [`UPGRADE-UNINSTALL.md`](UPGRADE-UNINSTALL.md)）。详见 [`DATA-DIRECTION.md`](DATA-DIRECTION.md)。
