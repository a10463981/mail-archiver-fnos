# 多磁盘怎么放（SSD 系统盘 + HDD 数据盘）

默认情况下，数据放在**系统分配的共享目录**（`data-share`，通常在 `/vol1/@appshare/mail-archiver-fnos/data`），安装时由 fnOS 自动创建并授权，**不需要**手工 `chown` 或授权。

如果你有独立 HDD 数据卷（如 vol2），希望归档数据放在数据盘上：

1. **先 `pg_dump` 导出**，再**卸载**（保留数据/删除数据都行，都不动 `@appshare`；**不要点「清理残留」**）—— 换位置必须在安装期决定，且换到新目录后是空库，旧邮件要靠 dump 恢复
2. 重装时在向导的「数据目录」里填 `/vol2/1000/<你的目录>`
3. 该目录需要应用运行用户可写：优先用平台「访问权限」授权应用；若该卷 ACL 不生效，再退回到 `chown -R 987:982 <目录>`
4. 装完启动，确认首页可打开、数据目录指向正确

**为什么不能热切换**：Docker 需要在容器启动时就 bind 挂载该目录，运行中无法热增挂载；强行切换意味着服务中断和数据搬一半的风险。

## 卸载 / 清理会删什么（实测）

| 操作 | `@appdata` 应用自有目录 | `@appshare`（data-share 默认位置） | `/vol1/1000/...` 用户指定目录 |
|---|---|---|---|
| 卸载 · 保留数据 | 保留 | **不删**（实测无 DeleteFile） | 不删 |
| 卸载 · 删除数据 | 删（仅删链接与私有目录；目标不动） | **不删**（09:34 实测，`last_uninstall_action=delete`） | 不删 |
| 应用中心「删除数据 / 清理残留」 | 删 | **会被删**（22:10 / 22:34 / 22:44 / 00:04 四次实测） | 不删 |

⚠ 四条硬事实（按实测）：

- **普通卸载（两种选项都算）不动 `@appshare`**（`08:58` 保留数据、`09:34` 删除数据两次实测均零 `DeleteFile`，重装复用同一份库）；
- **「应用中心 → 删除数据 / 清理残留」会把 `@appshare` 一起删**（22:10 / 22:34 / 22:44 / 00:04 四次实测）；
- **个人目录**（`/vol1/1000/...`、`/vol2/1000/...`）平台不碰 —— 想长期保住数据，装机时就指到数据盘；
- 无论放哪里，**操作前都先 `pg_dump`**（命令见 [`UPGRADE-UNINSTALL.md`](UPGRADE-UNINSTALL.md)）：**备份只能靠自己**。详见 [`DATA-DIRECTION.md`](DATA-DIRECTION.md)。
