# 升级与卸载

## 升级

平台不支持命令行覆盖已装应用，因此升级 = **卸载（保留数据）→ 手动安装新包 → 启动**：

1. 应用中心 → 本应用 → **卸载** → 选「**保留数据**」（不要选「删除数据」）
2. 应用中心 → **手动安装** → 选新版本 `.fpk`
3. 安装向导的密码**不生效**（检测到已有数据库），请用**原密码**登录
4. 启动后确认应用可访问；数据仍在原位置，沿用原账号与邮件

注意事项：

- 升级前建议备份数据目录（数据库在 `data/pgdata`，备份须包含整个目录或使用 `pg_dump`）
- **不要手工变更 PostgreSQL 大版本**（本包固定 16）；跨大版本需 dump/restore
- 卸载会保留 `@appconf` 下的数据库口令与加密密钥——**不要手删**，删了「保留数据重装」会因为新旧口令不匹配而失败

## 卸载

| 选项 | 应用自有目录 `@appdata/mail-archiver-fnos/data` | 系统共享目录（data-share） | 你自己的存储目录（数据根为符号链接时） | 目录记忆 |
|---|---|---|---|---|
| **保留数据** | 保留（旧库、旧账号） | **不删除** | 保留链接与目标 | 保留 |
| **删除数据** | 删除（数据库/附件清空） | **不删除**（用户可见的共享数据，误删代价高） | **只删符号链接本身**，目标目录不动（日志打印「保持不动」+ 绝对路径） | 清空 |

补充说明：

- 容器停止时不带 `-v`，数据是 bind mount，不会随容器删除而消失
- 卸载会移除「访问权限」中的目录授权记录；重装后若要再用个人目录，需重新授权一次
- 共享目录如需清理，请自行在文件管理器中删除；应用下次安装会重新指向它（沿用原有数据）
- **「删除数据」删的永远是应用自己的东西**；你自己的存储空间目录只能你自己删
