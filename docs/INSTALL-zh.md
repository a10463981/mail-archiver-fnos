## 📁 数据目录与卸载语义（重要，2026-10-28 更正）

**应用只管理自己的标准数据目录**：`/vol1/@appdata/mail-archiver-fnos/data`。
如果你把数据改到了别处（例如 `/vol1/1000/MailArchive`），那条路径只是**一个符号链接**，**目标目录由你管理，应用不会删除它**。

| 标准数据根形态 | 卸载选「保留数据」 | 卸载选「删除数据」 |
|---|---|---|
| **真实目录**（`@appdata/.../data` 是普通目录） | 保留整目录，重装沿用旧库与旧账号 | **删除该目录**（应用自有数据）；重装得到全新空库 |
| **符号链接**（指向你自己的目录，如 `/vol1/1000/MailArchive`） | 保留链接与目标，重装沿用旧库与旧账号 | **只删符号链接本身**；**你目录里的数据一点都不会动**（日志会打印"保持不动"+绝对路径，需自行清理） |

**安装时的判定**：只看标准数据根 `@appdata/mail-archiver-fnos/data`。
- 它不存在 → 全新安装，**向导里填的管理员密码会生效**；
- 它存在且里面有数据库 → 提示"沿用原有账号与密码，本次向导密码不生效"；若它是符号链接，还会额外提示"该目录不由应用管理，卸载/删除数据时不会删除它"；
- **不会**因为你自己的某个目录里恰好有 `pgdata` 就阻止安装。

> 换句话说：**"删除数据"删的永远是应用自己的东西；你的存储空间目录只能你自己删。**
