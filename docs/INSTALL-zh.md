# 安装说明（Mail-archiver for fnOS）

> 适用于 **26.10.01（正式首发）** 及后续 `26.10.x` 版本。安装包从 [Releases](https://github.com/a10463981/mail-archiver-fnos/releases) 下载（仓库只有 `26.10.01` 一个 Release）。

## 一、前置条件

- fnOS 系统版本 **≥ 1.2.0401**，架构 **x86_64**，内存建议 **≥ 4GB**
- 应用镜像**已内嵌在安装包内**（离线 `docker load`）；**唯一联网点是数据库镜像 `postgres:16-alpine`**，离线环境请先 `docker pull postgres:16-alpine`

## 二、安装步骤

1. 校验安装包：`sha256sum -c SHA256SUM.txt`（应为 `969a54cd…`）
2. 应用中心 → **手动安装** → 选择 `mail-archiver-fnos-26.10.01.fpk`
3. 向导填写：管理员用户名、**管理员密码（仅首次建库生效）**、时区（如 `Asia/Shanghai`）；**数据目录可留空**（走系统共享目录），要用数据盘再指定（如 `/vol2/1000/...`）
4. 完成 → **启动** → 从**桌面**打开「邮件归档」

首次登录会停在「修改密码」页，属上游对初始密码的保护，改一次即可。

## 三、日志与口令

- 应用运行日志：`docker logs --tail 200 mail-archiver-fnos`（**不是** `@appdata/.../logs`，该目录未使用）
- 安装日志中的管理员口令为**掩码**；**勿截图或外传安装日志**
- 密码语义与忘记密码的处理见 [`PASSWORDS.md`](PASSWORDS.md)、[`FORGOT-PASSWORD.md`](FORGOT-PASSWORD.md)

## 四、数据目录

- 默认放在系统分配的**共享目录**（`config/resource` 声明的 `data-share`），安装时自动创建并授权，**不需要**手工授权或 `chown`
- 要放数据盘（如 vol2），**在安装向导里指定**；**运行期不支持热切换**（Docker 需在启动时 bind 挂载），更换方式 = 卸载（保留数据）→ 重装指定
- **改数据目录不会搬运已有数据**：新位置是空库，旧数据留在原处。详见 [`DATA-DIRECTION.md`](DATA-DIRECTION.md)、[`DATA-DIR-SWITCH.md`](DATA-DIR-SWITCH.md)

## 五、安装时提示「存在安装历史」

平台在安装前会检查本应用残留。新版 `install_init` 会清理平台临时目录中的本应用残留并在日志写清清了什么；若平台在更早一步就拦住（脚本还没跑到），请手工删除下面两个路径后重装：

- `/vol1/@apptemp/mail-archiver-fnos`
- `/var/apps/mail-archiver-fnos`（若已不存在则忽略）

**只删这两个，别删别的。**

## 六、卸载

| 选项 | 应用自有数据根 | 系统共享目录（`data-share`） | 重装后 |
|---|---|---|---|
| 保留数据 | 保留 | 保留 | 沿用旧账号与旧密码（向导密码不生效） |
| 删除数据 | 删除 | ⚠ **平台会一并删除** | 全新空库 |

> **卸载前务必先备份**（`pg_dump` 或整目录复制）。完整语义见 [`UPGRADE-UNINSTALL.md`](UPGRADE-UNINSTALL.md)。

## 七、历史修复记录（仅供排障参考，不代表当前行为）

以下 6 条是 `0.1.16` 时期修的问题，均已被后续版本继承，写在这里只为解释旧日志里的报错文案：

| # | 修了什么 |
|---|---|
| MF-1 | 数据目录变更后自动重启并提示「新目录是空库、原数据保留在 `.bak-<时间戳>`」 |
| MF-2 | 安装日志只对「新建库」打印密码；沿用已有数据时提示「向导密码不生效」 |
| MF-3 | 口令以**掩码**打印，安装日志不含明文 |
| MF-4 | 设置页重置密码只调用一次 CLI（旧版两次导致双写库、双审计） |
| MF-5 | 数据清理白名单在 `TRIM_PKGVAR` 为空时直接拒绝，并精确匹配 `${TRIM_PKGVAR}/data` |
| MF-6 | 清理脚本缺失时安装中止（旧版会静默跳过「已有数据库检测」） |

> 注：`0.1.22` 起移除了运行期切换数据目录，改为只在安装/重装时决定数据位置。
